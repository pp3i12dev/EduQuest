🔔 EduQuest — Diagnóstico de notificaciones en Windows

Esta página no envía mensajes a Express ni cambia la suscripción de tu cuenta. Solo comprueba si el navegador puede crear una notificación local.

Presioná «Comprobar navegador».

Si la prueba dice «notificación registrada: sí» y no ves un banner, presioná Win + N para abrir el Centro de notificaciones. Después revisá Windows → Configuración → Sistema → Notificaciones: activá las de Chrome/Edge o EduQuest, habilitá banners y desactivá «No molestar».
